# Журнал дизайн-направлений

Заполняется после каждого проекта. Перед выбором направления для нового проекта — прочитать этот файл. **Занятые направления и занятые сигнатурные элементы не переиспользуются.**

Формат строки:

| Проект | Домен | Направление | Палитра (фон / текст / акцент) | Шрифты (display / body / data) | Сигнатура |
|---|---|---|---|---|---|
| _пример: avto-service_ | _автосервис_ | _цеховой журнал_ | _#12140F / #E8E4D9 / #C4451D_ | _Oswald / Inter / JetBrains Mono_ | _строка как бирка на детали: госномер моноширинно + вертикальная полоса статуса_ |

## Использовано

```
Проект:       ARÔME Admin
Домен:        розничная сеть парфюмерии (Туркменистан), каталог и цены
Направление:  «прайс-лист на бумаге» — тёплая бумага, волосяные линейки,
              Playfair Display + IBM Plex Sans/Mono, нулевые радиусы, без теней
Палитра:      #1B1512 / #E9E1D3 / #FAF6ED / #A2751E / #93251C / #4E6A46
Сигнатура:    строка товара как строка накладной: цветная полоса категории
              на всю высоту слева, перечёркнутая цена при скидке,
              статус подчёркнут снизу вместо «пилюли»
Занято:       тёплая бумажная палитра + Playfair — в следующих проектах не брать
```

| Проект | Домен | Направление | Палитра (фон / текст / акцент) | Шрифты (display / body / data) | Сигнатура |
|---|---|---|---|---|---|
| ARÔME Admin | розничная сеть парфюмерии (Туркменистан), каталог и цены | «прайс-лист на бумаге» | `#E9E1D3` / `#1B1512` / `#A2751E` | Playfair Display / IBM Plex Sans / IBM Plex Mono | строка товара как строка накладной: цветная полоса категории на всю высоту слева, перечёркнутая цена при скидке, статус подчёркнут снизу вместо «пилюли» |

Заметки для следующего проекта:

- Направление было **продиктовано брифом заказчика** (`AROMA-ADMIN-PROMPT.md`, §0), а не выбрано по каталогу — шаг 2 скилла пришёл уже заполненным.
- Навигация — **верхняя лента 56px + табы 40px, без сайдбара**; тёмная шапка при светлом теле. Верхнюю ленту с табами в следующем проекте лучше не повторять.
- Ось «открытие записи» здесь — модалка 660px поверх списка, «ввод» — сканер штрихкода. Обе оси свободны для комбинаций.
